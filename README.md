# DISCIPLINE 30

Персональный русскоязычный трекер дисциплины на 30 дней. Работает без регистрации и сервера, хранит прогресс локально в браузере.

## Запуск локально

PWA и Service Worker требуют HTTPS или localhost. В папке проекта запусти:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000` в браузере.

## Публикация бесплатно

Подойдут GitHub Pages, Cloudflare Pages или Netlify (статический сайт):
1. Создай репозиторий и загрузи **содержимое** этой папки.
2. Для GitHub Pages: Settings → Pages → Deploy from a branch → выбери `main` и `/ (root)`.
3. Дождись публикации и открой HTTPS-ссылку.

Никакие ключи, аккаунт внутри приложения или серверная база данных не нужны. Аккаунт на хостинге может потребоваться для самой публикации.

## Установка на iPhone

1. Открой опубликованный HTTPS-адрес в Safari.
2. Нажми системную кнопку «Поделиться».
3. Выбери «На экран Домой».
4. При наличии включи «Открывать как веб-приложение», затем нажми «Добавить».
5. Запускай с новой иконки DISCIPLINE 30.

Safari кэширует оболочку после первой загрузки. Для надёжной установки нужен HTTPS. Иконка SVG используется как PWA-иконка; поддержка SVG-иконок на старых версиях iOS может отличаться.

## Использование

- Вкладка «План»: переход между днями, 9 отметок и заметки с автосохранением.
- Пункт 8 засчитывает запланированную тренировку **или восстановление**. Выбирай восстановление при боли, болезни, недосыпе или чрезмерной усталости.
- «Календарь»: статусы всех 30 дней, нажми на дату для открытия чек-листа.
- «Статистика»: общий процент, серии, график по дням и прогресс по каждой привычке.
- «Ещё»: дата старта, экспорт/импорт JSON и сброс с подтверждением.
- «↥» в шапке быстро экспортирует резервную копию.

## Хранение данных и резервная копия

Данные находятся в `localStorage` этого браузера и устройства. Очистка данных сайта/браузера или переход на другой браузер может удалить их. Экспортируй JSON и храни копию отдельно. Импорт заменяет текущий прогресс содержимым файла.

## Структура

- `index.html` — разметка и экраны
- `styles.css` — адаптивный тёмный интерфейс
- `app.js` — логика, расчёты и локальное сохранение
- `manifest.json` — PWA-манифест
- `service-worker.js` — офлайн-кэш
- `assets/icon.svg` — иконка приложения

## Примечания

Это локальное приложение: синхронизации между устройствами нет. Даты 30-дневного плана считаются от выбранной даты старта. Приложение не отправляет уведомления и не собирает персональные данные.
